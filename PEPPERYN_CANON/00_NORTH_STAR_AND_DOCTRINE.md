# North Star and doctrine

## Product identity

Founder decision 2026-09-24: the public brand is **Insight Shaper**, continuing
the same Pepperyn product, not a fork or rebuild. Pepperyn terminology below
remains authoritative internal/historical terminology. All doctrine, capabilities,
contracts and evidence retain their authority; rebranding never licenses their
replacement. Public destination: `insightshaper.com`, activation not authorized.

Pepperyn is a persistent, temporal and proactive financial operating system for
a portfolio of SMEs. Its first professional hypothesis is:

> Can one Fractional CFO equipped with Pepperyn correctly manage more SMEs,
> with better continuity, lower mental load and better analysis quality?

Pepperyn is not a generic chatbot, an Excel summarizer, an LLM wrapper or a
dashboard whose truth changes with the current model.

## Governing doctrine

- **LLM != Pepperyn.** A model is a replaceable reasoning capability.
- Facts, doctrine, temporal state, provenance, epistemic status, memory,
  decisions, identity correspondence and governance belong to Pepperyn.
- Observation is not interpretation.
- Facts, inference, hypothesis, recommendation and confirmed professional
  decision remain distinct.
- `UNKNOWN` is an honest professional state.
- `CONTRADICTION` survives; it is not averaged away.
- Absence of evidence is not evidence of absence.
- No model or agent output becomes canonical truth automatically.
- Deterministic logic is preferred where it is more reliable.
- Provenance must survive to terminal consumption.
- Client and tenant isolation fail closed.
- Real identity disclosure to a provider is denied by default.

## Product sequence

Founder-transmitted professional review FR01–FR12 additionally establishes
professionally bounded usefulness: correct numbers do not ensure correct reasoning.
No automatic promotion from observation/signal/hypothesis through investigation,
established causality, economic impact and options to decision. Prudence is not
silence; explicit useful hypotheses remain unverified. UNKNOWN may lead to a
prioritized minimal information request and re-evaluation, not fabricated certainty.
Calculation does not license a professional semantic label; comparability and
evidence scope are governed. Normative details and source:
`docs/Product/FinancialReliability/professional-reasoning-doctrine-v2.md` and
`review-source-v2.txt`. These are requirements, not implementation or gate PASS.

`DATA -> NORMALIZATION -> DETERMINISTIC FACTS -> PROFESSIONAL DOCTRINE -> TEMPORAL CONTEXT -> GOVERNED REASONING -> VERIFICATION -> EPISTEMIC STATUS -> MEMORY -> DECISION -> FOLLOW-UP -> NEW FACTS -> CONTEXTUAL LEARNING`

No step may be invented merely to make the sequence appear complete. In
particular, execution is not an ActualOutcome; LaterEvidence, ActualOutcome and
Learning require genuinely later evidence. The existing synthetic decision has
no prospective ExpectedImpact and must not be retrofitted with one.
