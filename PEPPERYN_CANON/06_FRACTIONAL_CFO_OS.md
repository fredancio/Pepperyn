# Fractional CFO operating system

## Golden workflow

An authorized CFO can create distinct client companies, import admitted
financial data, obtain traceable analysis, retain context, return with a later
period, understand changes, retrieve prior decisions/actions and identify where
attention belongs without cross-client contamination or technical manipulation.

## Operating loop

`portfolio -> client card -> temporal state -> change -> attention -> evidence -> recommendation -> professional decision -> follow-up -> execution -> genuinely later evidence`

The loop does not imply that every execution creates an outcome or learning.
Those states require later evidence and an appropriate prospective measurement
contract.

## Beta evaluation

- analysis time and reconstruction time;
- correctness and correct refusal;
- continuity across periods;
- retrieval of prior professional decisions and conditions;
- identification of unresolved work;
- client prioritization quality;
- traceability of important conclusions;
- user trust and cognitive load;
- evidence that the CFO can safely manage greater capacity.
