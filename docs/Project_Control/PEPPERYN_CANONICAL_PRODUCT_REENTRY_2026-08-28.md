## 1. Executive verdict

Pepperyn on canonical `main` is a real, unusually broad financial-analysis product, not merely a collection of recovered architecture. It has authentication, organization/entity workspaces, file ingestion, an LLM analysis pipeline, executive results, PDF/PPTX/XLSX exports, analysis history and chat, billing controls, portfolio/review surfaces, decision memory, and a founder control surface. It also contains governed cognitive kernels for evidence, time, observation structure, economic meaning, doctrine, knowledge, uncertainty, admission/reconciliation, composition and passive OOXML reading.

Those two halves are not yet a single demonstrably field-safe professional workflow. Several governed kernels are canonical and tested but remain only partially connected to the product path. More urgently, the preferred Conversation Engine V2 sends a re-identified `ExecutiveCase V2` to Anthropic, while the public product promises anonymisation before AI processing. The main analysis path also has documented clear-text `relation_section`, `memory_section` and `actions_section` egress. This is a current trust defect, not a hypothetical future concern.

Therefore the shortest defensible path is:

1. close and prove the LLM-egress trust boundary for the exact first-client workflow;
2. replay one complete, isolated Founder engagement from onboarding to decision-ready output;
3. let observed professional friction select the next integration/product increment.

The next mission selected is **FIRST REAL-CLIENT LLM EGRESS TRUST GATE**. Portfolio Attention remains a validated user-test hypothesis and is not promoted to the roadmap.
