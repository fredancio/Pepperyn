## WHY and bounded change

The CFO must retain the same source-bound explanation of change when moving from
the client screen to a report. Before A23 the temporal API/UI existed, but governed
XLSX/PDF/PPTX exported only the current analysis and explicit decisions.

All three authenticated governed export routes now read the existing owned temporal
comparison using server-resolved organization and requested persisted analysis.
The existing loader verifies immutable envelopes, exact company/entity/engagement,
and selects the unique nearest earlier annual label. No caller supplies comparison
values or a previous analysis. Historical integrity or persistence failure returns
503 before any export bytes, never a successful "no history" fallback.

An appended section/sheet carries both analysis IDs, period labels, metric units,
source values, arithmetic differences and both fact IDs. UNKNOWN and CONTRADICTION
remain distinct; partial comparison retains its missing-input explanations. Renderer
checks current analysis/period/fact binding and refuses broadened comparability or
causal interpretation. They do not replace ownership/integrity checks in the loader.
Internal three-argument single-envelope renderer calls remain compatible and omit
this section; HTTP routes always request history and never use that fallback.

The scope is still ANNUAL_LABEL_ARITHMETIC_ONLY / financial comparability
NOT_ESTABLISHED. The technical COMPARABLE status is presented as arithmetic
availability, never as established professional financial comparability. No cause,
economic impact, outcome or learning follows from subtraction. Original facts,
recommendations, explicit decisions and their validation requirements are unchanged.
No new fact, decision, source dossier, analysis or memory is persisted.
